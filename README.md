# PowerBI-Retail-Sales-Analysis
 Retail Sales Analysis using Microsoft Power BI
 
Retail Sales Analysis – Power BI Portfolio Project

Project Overview

This project analyzes retail sales data using Microsoft Power BI to understand sales performance, profitability, customer behavior, and monthly trends.

Tools Used

- Microsoft Power BI Desktop
- Power Query
- DAX

Project Activities

- Data import and cleaning
- Data type validation
- DAX measure creation
- KPI dashboard development
- Product revenue and profit analysis
- Top 10 customer analysis
- Monthly revenue trend analysis
- Business insights and recommendations
